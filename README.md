# Senderos del Valle Central

Página de la presentación del piloto de trekking (DPRD): siete senderos con su video en 3D, el track con las señales para bajar (GPX), la señalización propuesta de cada uno y los tipos de señal dibujados. Se sirve en emilianosalasporta.cloud/senderos.

- `site/index.html`: la presentación (26 láminas).
- `site/videos/`: un video y su imagen de portada por sendero.
- `site/tracks/`: el track de ida y vuelta de cada sendero, con las señales como puntos.
